<h1 align="center">拾帧</h1>

<p align="center">macOS 菜单栏上的截图和录屏工具</p>

按 `⌃⌥A` 框选屏幕区域，可以标注、提取文字、翻译、截长图，或者录成 MP4 / GIF。所有处理默认都在本机完成，不收集任何数据。

## 下载安装

要求：macOS 15 及以上，Apple 芯片（M1 及以后）的 Mac。

1. 到 [Releases 页面](https://github.com/wuinan84-blip/shizhen/releases/latest) 下载 `shizhen-版本号-macOS-arm64.zip`，双击解压，把「拾帧」拖进「应用程序」文件夹。
2. 第一次打开时，macOS 会提示「Apple 无法验证"拾帧"是否包含恶意软件」。这是因为本应用没有经过苹果的付费公证，点「完成」即可。
3. 打开「系统设置 → 隐私与安全性」，滚动到「安全性」部分，在「"拾帧"已被阻止」旁边点「仍要打开」，输入开机密码确认。这一步只需要做一次。
4. 应用不在程序坞显示，只在屏幕右上角的菜单栏有一个图标。按首次启动的引导授予「屏幕录制」权限，然后重启应用。

第 2、3 步也可以用一条终端命令代替：

```bash
xattr -dr com.apple.quarantine /Applications/拾帧.app
```

## 权限

| 权限 | 用途 | 什么时候需要 |
| --- | --- | --- |
| 屏幕录制 | 截图、录屏、识别窗口，必需 | 首次启动 |
| 辅助功能 | 滚动截图的「自动滚动」（模拟滚轮） | 第一次点「自动滚动」时 |
| 麦克风 | 录屏时录制麦克风的声音 | 第一次打开麦克风开关时 |

授权状态可以在「菜单栏图标 → 设置… → 权限」中查看，未授权的项目有「去系统设置开启」按钮。

## 功能

### 截图

- 按 `⌃⌥A` 进入，鼠标所在的显示器画面会定格。移动鼠标自动识别窗口，单击选中；也可以拖动自由框选，再用 8 个控制点调整。
- 标注工具：矩形、椭圆、箭头、直线、马赛克、文字、标签、高亮。颜色和粗细会被记住；已画的标注可以移动、调大小、旋转，支持撤销和重做。
- 提取文字：离线识别选区里的中英文，结果可以编辑、复制。被马赛克盖住的文字不会被识别。
- 翻译：识别后翻译成中文。默认使用 macOS 自带的离线翻译（第一次翻译某种语言时，系统会联网下载语言包），也可以在设置里换成百度翻译。
- 滚动截图：手动滚动或自动滚动，实时拼接成长图（最高 30000 像素），完成后还可以继续标注。
- 结束：点对勾（`Enter`）把图片复制到剪贴板，点下载（`⌘S`）保存为 PNG，点叉（`Esc`）放弃。

### 录屏

- 在顶部的「截图 | 录屏」切换条选择「录屏」，框选区域后设置：MP4 或 GIF、麦克风、系统声音、显示鼠标（带点击高亮）。
- 3 秒倒计时后开始录制；浮动控制条可以暂停、继续、停止，菜单栏显示已录时长。
- 录完后在剪辑窗口里裁掉开头和结尾，然后复制到剪贴板（可以直接粘贴到微信、访达、邮件等能接收文件的应用），或保存为文件。
- MP4：H.264 视频 + AAC 音频，30 帧/秒。GIF：15 帧/秒，宽度超过 1280 像素时等比缩小。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `⌃⌥A` | 进入截图 / 录屏 |
| `Enter` | 完成，复制到剪贴板 |
| `⌘S` | 保存到文件 |
| `Esc` | 放弃；录屏倒计时中为取消录制 |
| `⌘Z` / `⇧⌘Z` | 撤销 / 重做 |

全部可以在「设置 → 快捷键」中修改。

## 百度翻译（可选）

1. 到[百度翻译开放平台](https://fanyi-api.baidu.com/)注册开发者，开通「通用文本翻译」。
2. 在「管理控制台 → 开发者信息」里找到 APP ID 和密钥。
3. 在本应用的「设置 → 翻译」里选择「百度翻译」，填入 APP ID 和密钥，点「测试」。

免费额度为每月 5 万字符，个人实名认证后每月 100 万字符（截至 2026 年 11 月，以百度官方说明为准）。APP ID 和密钥保存在 macOS 钥匙串里，不会以明文写入配置文件。

## 隐私

- 截图、文字识别、离线翻译、录屏都在本机完成，不联网。
- 只有在设置里选择了百度翻译后，识别出的文字才会发送到百度服务器。
- 不收集任何使用数据。
- 把录屏复制到剪贴板时生成的临时文件放在 `~/Library/Caches/com.wuyinan.jietu/`，24 小时后自动删除。

## 从源码编译

需要 macOS 15 及以上，以及 Xcode 16 及以上（或带 Swift 6 的 Command Line Tools）。

```bash
git clone https://github.com/wuinan84-blip/shizhen.git
cd shizhen
./scripts/build.sh
open build/拾帧.app
```

第一次运行 `build.sh` 时，会在 `.signing/` 里生成一张只在本机使用的签名证书，之后每次编译都用它签名。这样重新编译后，系统授予的屏幕录制等权限不会失效。
